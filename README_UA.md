# NOMIKO v0.8.2 Alpha — Windows 11

**NOMIKO** — особистий незалежний проєкт браузера. Працює на PySide6 / Qt WebEngine / Chromium, має власну оболонку, локальне зберігання та кастомізацію. Ця збірка — експериментальна, **НЕ перевірений анонімний браузер**.

## Запуск на Windows 11

1. Закрий попередній NOMIKO.
2. Зроби копію папки `%APPDATA%\NOMIKO` на всяк випадок. Це твої локальні налаштування, закладки та історія.
3. Розпакуй ZIP у **нову** папку. Не запускай файли безпосередньо всередині ZIP.
4. Запусти `run-windows.bat`. Він шукає наявний 64-бітний Python 3.15 (або сумісний Python 3.10–3.15), створює `.venv` та встановлює залежності з `requirements.txt`. Для першого встановлення залежностей потрібен інтернет.
5. Для власної спроби створити Windows EXE запусти `build-windows.bat`; потрібен PyInstaller і ресурси для Qt WebEngine. Готового скомпільованого EXE **в цьому ZIP немає**.

`%APPDATA%\NOMIKO` залишається спільною локальною папкою для звичайних версій. Приватні вікна не зберігають історію NOMIKO, але не приховують IP.

## Виправлення v0.8.2 — плавне перетягування бокових вкладок

Якщо вкладки розміщені **зліва або справа**, затисни вкладку лівою кнопкою
миші та перетягни вгору чи вниз. Це працює і в компактному режимі **лише
фавіконки**, і в режимі **фавіконка + назва**. Сусідні вкладки плавно
звільняють місце, а новий порядок зберігається через звичайний механізм
сеансу NOMIKO. Звичайне натискання перемикає вкладку, а натискання на X
закриває її. Перетягування фонової вкладки більше не перемикає на неї.

**Уточнення:** автоматичні тести пройдено, але реальний drag-and-drop на
Windows 11 ще не перевірено — перевір після запуску.

## Головні новинки v0.8

- **Вкладки:** пошук усіх вкладок (Ctrl+Shift+A), закріплення/відкріплення через ПКМ, вибір групи Work/Study/Games/Personal через ПКМ. Назви груп — мітки, **не повні згортні групи Firefox**. Для вебвкладок групи та pin відновлюються, якщо увімкнено Restore tabs.
- **Workspaces:** локальне збереження назви та набору URL; відкриття робочого простору додає вкладки в поточне вікно (не замінює наявні). Не використовується в приватних вікнах.
- **Split View (v0.8.1):** дві незалежні вебпанелі. У КОЖНОЇ є свій адресний/пошуковий рядок, кнопка пошуку, назад/уперед, оновлення, Home та власний вибір DuckDuckGo / Google / NOMIKO Search. Права половина відкривається з власною домашньою сторінкою; розміри половин можна змінювати, перетягуючи роздільник. Ctrl+L фокусує пошук активної половини. У режимі NOMIKO Search відображаються лише локальні закладки та історія, без Wikipedia і власного глобального вебіндексу. Split View поки не відновлюється після перезапуску.
- **Reading mode:** Ctrl+Shift+R перетворює доступний HTML на локальну сторінку з текстом без виконання коду сайту. Це простий парсер, тому складні статті можуть відобразитися неповністю.
- **Picture-in-Picture:** експериментальна команда, яка просить сайт/Qt відкрити відео у PiP. Може не підтримуватися або бути відхилена сайтом.
- **Імпорт/експорт:** Firefox/Chrome-формат HTML-закладок; архів ZIP із локальними налаштуваннями, закладками, історією, робочими просторами та іншими JSON-файлами. **Cookies, WebProfile та паролі не включаються.** При відновленні створюється копія попередніх файлів. Після відновлення слід повністю перезапустити NOMIKO.
- **Password Vault (Windows):** локальні логіни зашифровані DPAPI для поточного облікового запису Windows; додавання, видалення, копіювання пароля з очищенням буфера через 20 с. **Автозаповнення відсутнє**. Ніколи не клади папку паролів у публічний репозиторій.
- **Theme Studio 2.0:** готові пресети, шрифт, акцент, змішування кольорів, перевірений JSON-імпорт/експорт тем; старі налаштування не скидаються.
- **Local Blocklist:** імпорт текстового `hosts`-списку рекламних/трекерних доменів до 2 МБ, до 22 000 записів. Блокує тільки відповідні сторонні запити. Це **не** WebExtensions, не повноцінний uBlock Origin, не автоматичне оновлення списків.
- **Privacy:** попередження під час переходу на HTTP, обережне попередження про Punycode/IDN-домени, попередження перед завантаженням файлів, які можуть запускати код. Користувач може обрати продовження. Це **не** інтернет-служба перевірки фішингу чи антивірус.
- **Performance:** живий монітор кількості вкладок, обраного режиму та робочої пам'яті **лише основного процесу**; Chromium subprocesses окремі. Залишено режими Gaming/Ultra зі старої версії. FPS у Fortnite не вимірювався.
- **Windows Build:** `build-windows.bat` і шаблон GitHub Actions для компіляції portable EXE та NSIS інсталятора на Windows. Збирання ще не перевірене у Windows CI.

Доступ до нових інструментів: **Menu → NOMIKO tools**, а також розділи **Settings → Appearance / Workspaces / Data & backup / Privacy / Modules**.

## Що ПОКИ НЕ готово для повноцінного релізу

- Немає сервера й механізму **криптографічно підписаних автоматичних оновлень**. Оновлюй вручну, не завантажуй невідомі EXE з випадкових сайтів.
- Немає повної бази небезпечних/фішингових сайтів, незалежного аудиту, повноцінного anti-fingerprinting, VPN/Tor, перевірки мережевих витоків та захищеної анонімності.
- Немає звичайних Chrome/Firefox-розширень і безпечного каталогу сторонніх виконуваних плагінів. Qt WebEngine не надає стандартний WebExtensions API.
- Менеджер паролів не заповнює форми автоматично; DPAPI не гарантує захист від шкідливого ПЗ в уже розблокованому Windows-акаунті.
- Переклади багатьох із 70 доступних мов неповні.
- Продуктивність, PiP, Split View, Vault та графічний інтерфейс **ще не перевірені на Windows 11**. Якщо NOMIKO падає, збережи текст консолі `run-windows.bat`.

**Для банкінгу, важливих паролів та конфіденційних дій поки використовуй регулярно оновлюваний перевірений браузер.**
